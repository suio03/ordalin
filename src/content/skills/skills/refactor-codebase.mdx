## What we tested

We wrote a small invoicing app for the command line in TypeScript: customers, quotes and invoices stored in a JSON file, with a report of outstanding and paid totals. It had 419 lines and 10 tests, one of them skipped. We gave it the debt that builds up when an assistant adds features over several sessions: the price calculation (subtotal, one customer's 5% discount, 10% tax, rounding) written separately in four places, invoice status kept in three true/false flags, the currency passed between modules through a global object, a storage "driver" factory with one driver, a plugin system with one empty plugin, an unused CSV export, a retry loop that swallowed errors, and a skipped test marked "flaky on CI".

We installed refactor-codebase from the repository at commit 873aba8, together with the six skills it links to, and sent one message starting with /refactor-codebase, using Claude Fable 5.2 in Claude Code. The agent could read and edit files, run commands, commit with git and start subagents. Afterwards we read every commit, ran the tests, and ran the same commands against the starting code and the result.

## What we found

- **It followed its own process.** Two subagents hunted for state machines and overengineering without changing anything, while the main agent wrote a refactor list with each fix above the problems it removes. It then landed six fixes as six commits, sent a fresh subagent to re-audit, acted on what it found, ran a final search, and finished with two test-audit commits.
- **It found real bugs.** A cancelled invoice could still be paid and was then counted as paid income; accepting the same quote twice created a second invoice; and a broken data file was read as empty, so the next command overwrote everyone's data. We had planted the swallowed errors, but not the first two. Each fix is named in its commit message, and we confirmed all three by running both versions.
- **It removed what had no reason to exist.** The plugin system, the storage factory, the config object, the global state, the CSV export and an old validator are gone; a new 18-line billing module owns totals, validation and numbering for both quotes and invoices.
- **The tests got stronger.** The skipped test became a real one, a test that only compared the quote code with a copy of itself was given fixed expected values, and regression tests cover each fixed bug. 15 tests pass.
- **One file outside the folder.** Despite our instruction, the agent left a scratch file in the system temp folder. Its tests, like our originals, also leave temporary folders behind.

The run took 30 turns, 11 minutes and $6.71 at API prices, as reported by Claude Code. This is one small, purpose-built app with one model, so read it as an example of what the skill does, not a benchmark.
