## What we tested

We installed the skill from commit 2e6396a into a fresh project folder and gave Claude Code on Claude Opus 5.5 two briefs, one run each. Both are the README's own examples, translated into English: the B3 particle brief written for Codex, and the Z5 paper-cut New Year opener written for Claude Code. We asked for an editable HTML file, keyframes and an MP4 every time, and told the agent to keep any Python packages in a local virtual environment.

## What we found

- **Both runs delivered.** Each produced an MP4 of exactly 12.000 seconds at 1920×1080 and 30 fps with no audio track, an HTML file with the main settings in one config block, and a set of keyframes. B3 took 4.5 minutes and $0.76 at API prices, Z5 3.8 minutes and $0.85.
- **The agent checked its own work.** In the B3 run it looked at its contact sheet, found the captions too faint and fixed them before the final render. The Z5 run rendered the same frame twice to confirm the export was deterministic.
- **The style prompts carry the look.** B3 came out as 5,000 gold particles that form a light bulb, a wall of bricks and a checkmark; Z5 as layered red paper with soft shadows. The brick shape in B3 was the least readable of the three.
- **One setup problem in both runs.** The rendering guide tells you to run python -m playwright install chromium. Inside a virtual environment that still downloads Chromium and an FFmpeg build into the cache Playwright shares across the machine. Both agents noticed and removed what they had added, but setting PLAYWRIGHT_BROWSERS_PATH avoids it.
- **The agent fills gaps on its own.** Asked for an English line, the Z5 run added the good-fortune character as the centrepiece and picked the font itself. That fits the brief, but check the details if you need exact branding.

## A compilation, credited

Code Animation Prompts is honest about being a compilation, and the README credits every source. Just under half of the 341 entries come from Lemo-Opuscar, 46 from mg-styles-15 and code-video, and the rest from the collection's own series. What XiaoyeCodes adds is the packaging: the skill instructions, the search tool, the offline picker, the starter page and the renderer.
