## What we tested

We wrote a small pricing page for a made-up invoicing app, Ledgerly, with the habits Impeccable targets: Inter, a purple gradient hero, gradient headline text, light grey text, emoji icons, pill buttons and a scaled-up "Most Popular" card. Impeccable's own detector found 26 problems in it.

We asked Claude Code to polish it once with the Impeccable plugin loaded from the repository at commit f864521 (plugin version 4.8.0) and once with nothing installed. Both runs used the same model and settings, could read and edit files and run commands, and got the same brief: calm and trustworthy, keep the copy and prices, no questions. The plain run's request was the same sentence without the /impeccable command. We then ran Impeccable's detector on both results. The test sessions also had a few of our own general skills loaded, the same for both runs.

## What we found

- **Both pages came out calm and close to each other.** Each run removed the gradients and emoji, chose a serif for headings, a single deep green (#1f5a47 in both) as the only accent, outline icons, equal-height plan cards and visible keyboard focus. The plain run also added a sample invoice beside the headline, with a client and amounts it made up.
- **Impeccable checked its own work.** It ran the skill's context step, read the polish and craft playbooks, wrote a first version, then ran the detector. The detector flagged a cream background and cramped padding in three sections; the agent switched to a cool grey and fixed the padding, then took its own screenshots at three widths.
- **The detector scored the plain page lower.** On the finished files, the plain page had three findings (Inter, a cream background, the buzzword) plus two lines of grey text at 4.4:1 contrast, just below WCAG AA. Impeccable's page had one: "Supercharge" in the headline we told both runs to keep. This is the skill's own checker grading its own rules, so read it as "it followed its rules", not as an independent score.
- **It respected the brief.** To silence the buzzword warning it briefly created an .impeccable/config.json, then deleted it because we had said to touch only two files, and told us how to keep it if we wanted.

The Impeccable run took 24 turns, 149 seconds and $0.83 at API prices, as reported by Claude Code. The plain run took 12 turns, 86 seconds and $0.41. Both runs saved screenshots to the system temp folder. This is one small page with one model, so read it as an example, not a benchmark.
