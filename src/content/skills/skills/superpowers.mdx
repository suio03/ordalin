## What we tested

We wrote a small to-do app for the command line, in TypeScript with four tests, and asked Claude Code to add due dates: an optional `--due` date on `add`, the date shown in `list`, a `list --overdue` filter and a clear error for invalid dates.

We ran it once with the Superpowers plugin loaded from the repository at commit 22f0b46 (plugin version 7.0.2) and once with nothing installed. Both runs used the same model and settings and could read and edit files and run commands. Because Superpowers is built to ask questions and get a design approved before coding, each run was a three-message conversation: the request; then "pick sensible defaults, I approve the design, go ahead with the next step"; then "implement it now, finish the work and tell me when it's done". We checked the plugin's start-up hook ran and all 15 skills were listed. We then ran each project's tests. The test sessions also had a few of our own general skills loaded, the same for both runs.

## What we found

- **It wrote tests first.** The Superpowers run loaded the test-driven development skill as its first step, wrote failing tests, ran them to see them fail for the right reason, then wrote the code, once for the data layer and once for the command line. The plain run wrote all the code first and added tests afterwards.
- **It tested more.** It finished with 12 passing tests, six of them running the real command in a fresh folder. The plain run finished with 6 passing tests for the data functions and checked the command by hand. Both handled the same edge cases, such as 30 February, and both added the option to the README.
- **Brainstorming and planning did not start.** The agent never loaded the brainstorming, writing-plans or finishing-a-development-branch skills. It implemented the feature in the first message, so our second and third messages only led to a commit and a merge, which both runs did the same way. In an earlier one-message try that said "don't ask me questions", no Superpowers skill loaded at all.
- **Its tests leave files behind.** Each command-line test creates a temp folder and does not delete it. After a few test runs we found 20 of them in the system temp folder.

The Superpowers run took 16 turns, 73 seconds and $0.39 at API prices over the three messages, as reported by Claude Code. The plain run took 12 turns, 59 seconds and $0.29. This is one small feature with one model, so read it as an example, not a benchmark.
