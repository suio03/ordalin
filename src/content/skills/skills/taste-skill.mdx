## What we tested

We asked Claude Code for a one-page website for an invented Melbourne bakery: sourdough, pastries, opening hours, an address and a way to order celebration cakes by email, in plain HTML and CSS, without asking questions. We ran it once with the skill copied in from the repository at commit 12af471 (version 2.1.5), naming the skill in the request, and once with nothing installed. Both runs used the same model and settings, could read and write files, run commands and use the web, and had Node and Chrome available. The test sessions also had a few of our own general skills loaded, the same for both runs.

## What we found

- **It did not look like the average page.** The plain run made the familiar cream page: a small uppercase label over a large serif headline, two rounded buttons, a dark card with the hours and thin dividers between sections. The skill's run was built as the shop's own hours card in pink over a burgundy ground, with one heavy typeface throughout.
- **It used real, credited pictures.** It searched open collections, downloaded a view of Brunswick East, a photograph of Lygon Street (captioned honestly as further down in Carlton), an 1878 rye field by Ivan Shishkin, two old oven prints and a short oven video, and listed every credit in the footer. The plain page had no pictures at all.
- **It checked itself and kept fixing.** The first browser check failed seven rules, including headlines wrapping to three lines and a headline hidden under a picture on tablet. After six checks it passed with one warning, and both pages read well on a phone.
- **It made up details.** The skill's page priced 32 items, from a $5.50 croissant to cakes from $65, and printed a baking timetable. None of that was in the brief. The plain run invented menu items but no prices.
- **It cost much more and weighed more.** The skill run took 61 turns, 18 minutes and $5.15 at API prices; the plain run took 12 turns, 104 seconds and $0.42. The skill's page also added a 6.7 KB script for an open-or-closed sign, the order form and motion, and 6.5 MB of pictures and footage, against two small files.

This is one brief with one model, so read it as an example, not a benchmark.
