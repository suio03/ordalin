- **It delivered a finished film.** The result was a 62-second MP4 at 1920×1080 and 24 fps, with an original score, sound effects synced to each pen stroke, nine subtitles and loudness normalised to −14 LUFS. It stuck to the three facts in the brief.
- **The tooling is the strong part.** Rendering, audio sampling, sound design, the readability check and the final mix all came from the repository and worked first time. Rendering all 1,498 frames took 18 seconds.
- **The film itself is still written by the agent.** About 500 lines of new code (the shots, the score and the mix) were the agent's own, drawing heavily on the style's demo. Its own estimate was roughly 15 minutes of work after reading the guides, which it called a lower bound.
- **We hit a few rough edges.** The whiteboard demo references a handwriting font the repository does not include, so the agent downloaded it. The readability check needs a hook the demo page does not provide. There is no general subtitle exporter, and the guides assume a narrated film. Most comments in the core tools are in Chinese.
- **Competent, not stunning.** The style was there: a glossy board, a floating marker, magnets as the only moving objects. But the opening is slow without a voice, the full-board pull-back near the end looks sparse, and the final hold runs a little long.

## Make a style your own

A second version of this feature arrived on 2026-10-22. Our test run came before it, so this section follows the README and the author's MY-STYLES.md guide in the repository rather than our own run.

- **Two ways in.** Change one of the 99 library styles, for example turning Ukiyo-e into a "Night Ukiyo-e", the README's own example. Or start from a blank page: describe the look, or share a picture or a film you like, and the agent picks the closest library style as the technique base and tells you why. Typing `/lemo-opuscar:lemo-opuscar` on its own opens a menu with both options.
- **Planned one question at a time.** Each question has a few options with a recommendation first: what the films are for, which platform and aspect ratio, brand colours, logo, fonts or recurring characters, then what to change. For a library style, the agent first sorts it into what is safe to change (palette, type, pace, sound), what changes its character (materials, colour logic, camera) and what cannot change without it becoming a different style. Vague wishes such as "more premium" are turned into concrete choices, and at most five changes are allowed per round.
- **Nothing is written until you agree.** You review a before-and-after summary, then see one style frame drawn with the real code, next to the original when you changed a library style. If it still isn't right after two rounds, the agent says so and suggests a closer base style.
- **A short demo film, then you keep it.** The agent makes a 15 to 30 second demo with every change on screen, checks it once, and asks whether to keep it. Kept styles live in `~/lemo-my-styles/` with their style sheet, list of changes and demo, are listed first when you pick a style, and survive updates and uninstalls. When the base style is later updated, the agent asks once whether to bring the fixes into your copy.
- **Still code only.** Every change has to be something code can draw; there is no image generation.
