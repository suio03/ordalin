## What we tested

We wanted to see the pack run end to end on real data with an outcome we could check, without a broker. So we picked a finished session, Wednesday 4 November 2026, and asked Claude Code to replay it as if it were 10:15 AM New York time: scan for opening-range breakouts, pick the strongest, plan the stop and target, run the Time Machine, size the trade for a $5,000 paper account with a $50 max loss, place nothing, and then say whether the stop or the target was hit first.

The plugin was loaded from the repository at commit 3d0f4ef (version 2.0.0). Claude Code saw all 11 skills, ran the scanner, entry, exit, Time Machine and budget tools with the --now flag set to 10:15, and saved every step into a trader/ folder.

## What we found

- **The pipeline ran without help.** Universe, scan, entry check, exit plan, 10,000 replays and sizing took 9 minutes and 28 turns. Every number in the answer traces back to a JSON file the tools wrote, and the scanner says plainly when it checked only part of the list (200 of 1,025 candidates).
- **The agent chased.** It picked DUOL because it was furthest above its opening range at 10:15, up 36% on the day. The breakout had fired at 10:00 at 165.79; by 10:15 the price was 174.24. trader-entry said "A late entry is a different trade". The agent used the late price anyway, which put the stop 7.74% away and the 2R target at 201.22, 15% above the entry.
- **The Time Machine could not see this day coming.** Built from DUOL's previous 46 ordinary sessions, the replays put 100% of outcomes between the lines at the close, with a median of 174.50. On the real day DUOL had opened 26% above the previous close and kept swinging. The tool prints its own warning that news and earnings can do what past sessions never did, and this was that case.
- **The sizing worked as promised.** The $50 max loss allowed 3 shares, $522.72. The stop filled near 160.75 on the 15:10 bar, so the paper loss was about $40, inside the limit. A late stop-out is exactly what the size is for.
- **It skipped a step.** The agent never ran trader-news, which the README puts second in the flow. A news check would have shown why DUOL was up 36% that morning.

One replayed trade with one model is an example, not a measure of the strategy. The agent did the arithmetic right; the trade it chose was the problem.
