## What we tested

We installed the eleven skills into an empty test project and gave Claude Code one request: study Memos, the open-source note-taking web app, so we could build our own version of its core loop, which is writing a memo, tagging it and finding it again. We limited the sources to its public website and documentation. Memos is MIT-licensed, so rebuilding it raises no terms-of-service question.

We sent the same request twice: once with the skills installed in the project, and once with the same model and nothing installed. Both runs loaded project settings only and could read web pages and write files.

## What we found

- **The skill picked the recon step itself and followed it.** It wrote replica/recon.md, a 14 KB map with 15 numbered sources, 12 screens, 7 flows with click counts and edge cases, a component table, a data model with evidence and a confidence level for each entity, the exact tag rules and a size estimate of M. It also wrote replica/features.csv with 47 rows: 17 must, 13 should, 8 could and 9 skip. It ended by naming the next skill to run.
- **It marked its guesses.** Screens and actions the docs do not describe, such as the sidebar tag list, the memo action menu and the save shortcut, are labelled as guesses rather than stated as facts. It left the screenshots folder empty and said so.
- **It kept the brand out.** The Memos name and logo are a skip row, and the out-of-scope list sends you to pick your own name.
- **The run without the skill was also good.** It wrote one 15.6 KB spec covering the same tag rules, data model, filter language and calendar, marked each point as documented or inferred, added a suggested SQLite schema and a build order, and listed open questions. What it lacked was the structure the later Replica steps depend on: numbered screens and flows, click counts, a prioritised feature list with skip rows and a size estimate.
- **Neither run read the source code or opened the demo,** because we asked them not to. A real rebuild would likely check both.

The run with the skill took 22 turns and about three minutes and cost $0.63 at API prices, as reported by Claude Code. The run without it took 17 turns and cost $0.50. This is one small test of the first of eleven skills, on one well-documented open-source app. We did not test the architect, design, build, backend, test, diff, entrepreneur, brand, launch or deploy skills, the Python tools, the plugin install, or an app with thin public documentation.
