## More self-hosted options

These smaller open-source projects also give you a personal agent you run yourself and message from chat apps. Facts come from each project's GitHub README.

### NanoClaw

[NanoClaw](https://github.com/nanocoai/nanoclaw) is an MIT-licensed agent where each agent runs in its own Linux container, so its tools don't run directly on your machine. It is built on Anthropic's Claude Agent SDK; other providers such as Codex, OpenCode and Ollama are added through skills. You reach it from Slack, Telegram, Discord, WhatsApp, iMessage or the command line. Setup installs Node, pnpm and Docker.

### ZeroClaw

[ZeroClaw](https://github.com/zeroclaw-labs/zeroclaw) is a single Rust binary, dual-licensed MIT or Apache 2.0. It works with Anthropic, OpenAI, Ollama and about 20 other providers, connects to 30+ channels including Discord, Telegram, Matrix, email and webhooks, and has shell, browser, HTTP and MCP tools. It runs on Linux, macOS, Windows, FreeBSD and Docker.

### nanobot

[nanobot](https://github.com/HKUDS/nanobot) is an MIT-licensed Python agent from HKUDS that runs in a web UI or terminal. It connects to Telegram, Discord, Slack, WeChat, email, Mattermost, Microsoft Teams, Feishu and more, with long-term memory, MCP tools and scheduled tasks. Its docs include a setup guide for people without a technical background.

## How we picked

We started from what OpenClaw does: a personal agent you install yourself and message from chat apps. Then we sorted the alternatives by the part of that design they change: who hosts it, whose model it uses, and where its tools run. Prices and features come from each maker's own pages, and every claim above links back to them in the sources list.

We didn't rank on hands-on testing yet. Where a maker hasn't published something, such as regions or free-tier limits, we say so rather than guess.
