# Ordalin design decision — Round 02

Date: 23 August 2026
Status: approved main theme
Selected direction: **04 · Quiet Radar**

## Preserve

- Calm orientation rather than a loud marketplace.
- Search-first, but never search-only: useful inventory remains visible immediately.
- Mist-white and mineral-blue fields with graphite text.
- Green reserved for freshness, active state, and verified-positive feedback.
- Approved monochrome Editorial Cut logo, unchanged.
- Subtle coordinate/grid cues without a literal radar graphic.
- Solid, performant layers rather than blur-heavy glass.

## Refine

- Raise panel and secondary-text contrast so the atmosphere never weakens legibility.
- Tighten the first viewport so search, all ten categories, Today/New, filters, tools, Editor Picks, and Collections read as one system.
- Make source/freshness metadata visible but quieter than tool purpose.
- Give focus, selected, empty, and reset states explicit accessible feedback.
- Define the compact transformation at 390 px using the approved MVP mobile order.

## Out of scope

- Dark mode.
- Full product implementation or additional routes.
- Accounts, saves, reviews, comparisons, sponsorship, or fictional engagement data.
- Any design direction other than Quiet Radar unless a new decision explicitly replaces it.
