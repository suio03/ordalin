# Ordalin design research

Research date: 22 August 2026
Target: desktop-first public web product homepage, 1440 px reference viewport
Scope: visual and interaction direction only; no production UI implementation

## Confirmed brief

Ordalin is an inventory-first directory for finding reviewed AI tools through search, deterministic filters, categories, new arrivals, editor picks, and curated collections. The homepage is the product entry surface—not a marketing landing page. It should feel trustworthy, clear, perceptive, and editorial while avoiding the saturated gradients, magic effects, robots, and speculative claims common to AI directories.

The MVP uses a light application theme only. The approved Editorial Cut logo remains monochrome and unchanged.

## Cross-reference findings

1. Search should be prominent but should not gate discovery. The user must see useful inventory before typing.
2. “Today” and “New” need explicit, deterministic meaning. Engagement labels are omitted because Ordalin has no first-party save or usage data at launch.
3. Category navigation should expose the ten launch categories without turning the whole page into a taxonomy dump.
4. Tool rows need factual purpose, primary category, pricing model, freshness, and an unambiguous Visit action.
5. Editor Picks and Collections should read as authored navigation—not sponsored promotion.
6. Trust comes from source and freshness cues, restraint, and consistent structure rather than badges or invented scores.

## Frozen homepage skeleton

All four directions use this exact content and functional order:

1. Global navigation: Tools, Categories, New, Collections, About ranking, Submit a tool.
2. Compact promise: “Find the right AI tool, without the noise.”
3. Catalogue search.
4. Ten top-level categories: Writing, Image, Video, Audio, Coding, Productivity, Marketing, Research, Agents, Other.
5. Today/New browse state and deterministic filters for category and pricing.
6. Twelve real example tools with the same name, factual purpose, category, pricing model, freshness, and Visit action.
7. Editor Picks with explicit editorial wording.
8. Three curated collections.
9. Ranking-methodology shortcut and pagination.

The content is deliberately identical in every direction. Only composition, typography, material, shape, color role, icon treatment, and motion character may change.

## Source limits

This audit verifies that the referenced products and stated behaviors are currently represented on their official pages. It does not claim that any visual choice caused product success. No competitor screenshots, signature illustrations, icons, or copy are reproduced.
